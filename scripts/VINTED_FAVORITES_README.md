# Vinted Favorites Scraper

Скрипт для скачивания всех ваших избранных товаров с Vinted.

## Как работает пагинация

Vinted API возвращает `next_page_token` в ответе вместе с данными. Этот токен используется для получения следующей страницы:

```json
{
  "items": [...],
  "pagination": {
    "next_page_token": "1762267417"
  }
}
```

Скрипт автоматически извлекает этот токен и использует его для следующего запроса.

## Подготовка

### 1. Получите актуальные cookies и токены

Cookies и токены имеют ограниченный срок действия, поэтому их нужно обновлять перед каждым запуском:

1. Откройте https://www.vinted.com/member/items/favourite_list в браузере
2. Откройте DevTools (F12)
3. Перейдите на вкладку Network
4. Обновите страницу (F5)
5. Найдите запрос к `/items/favourites`
6. Скопируйте следующие значения из Headers:

**Cookie header:**
- Найдите `Cookie:` в Request Headers
- Скопируйте всё значение

**x-csrf-token:**
- Найдите `x-csrf-token:` в Request Headers
- Скопируйте значение (например: `75f6c9fa-dc8e-4e52-a000-e09dd4084b3e`)

**x-anon-id:**
- Найдите `x-anon-id:` в Request Headers
- Скопируйте значение (например: `4683f9ba-2b34-4e70-b480-65784e53e2a0`)

**User ID:**
- Из URL запроса `/users/{USER_ID}/items/favourites`
- Скопируйте цифры (например: `88588889`)

### 2. Обновите скрипт

Откройте `scripts/fetch-vinted-favorites.ts` и обновите константы в секции CONFIGURATION:

```typescript
const USER_ID = 'ВАШ_USER_ID';
const COOKIES = 'ВАШ_COOKIE_STRING';
const CSRF_TOKEN = 'ВАШ_CSRF_TOKEN';
const ANON_ID = 'ВАШ_ANON_ID';
```

## Запуск

```bash
# Установите зависимости (если еще не установлены)
yarn install

# Запустите скрипт
yarn fetch:favorites
```

Или напрямую:

```bash
ts-node --project tsconfig.scripts.json scripts/fetch-vinted-favorites.ts
```

## Результат

Скрипт создаст два файла в `data/vinted/`:

1. **favorites.json** - полный список с деталями:
```json
[
  {
    "id": 12345,
    "title": "Vintage Nike Jacket",
    "brand": "Nike",
    "price": "25.00",
    "url": "https://..."
  }
]
```

2. **favorites-list.txt** - простой список:
```
Vintage Nike Jacket - Nike
Adidas Sneakers - Adidas
Zara Dress - Zara
```

Также в консоли будет показана статистика:
- Общее количество товаров
- Топ-10 брендов в избранном

## Особенности

- **Автоматическая пагинация**: скрипт автоматически обходит все страницы
- **Rate limiting**: между запросами есть задержка в 1 секунду
- **Обработка ошибок**: если токен истек, вы увидите ошибку 401/403
- **Прогресс**: показывает прогресс обработки страниц

## Troubleshooting

### Ошибка 401/403
Ваши cookies или токены устарели. Обновите их, следуя инструкциям выше.

### Ошибка 429 (Too Many Requests)
Слишком много запросов. Увеличьте `DELAY_BETWEEN_REQUESTS` в скрипте.

### Пустой результат
Проверьте, что:
- USER_ID правильный
- Вы залогинены в браузере
- У вас есть избранные товары
